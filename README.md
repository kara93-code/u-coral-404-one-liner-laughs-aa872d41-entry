One funny line about a suitcase that came home heavier than it left:
it ate better on holiday than its owner did.

## The line

> My suitcase weighed 23 kilos at check-in and 24 at home, which means it ate better on holiday than I did.

105 characters, one line, one read. Two specific numbers set the scene,
and the twist lands on the last words: the suitcase, not the traveller,
is the one that ate well.

## How it runs

`main.ts` (Node 22) writes the line to `/output/entry.txt`
(`$MAKEFUN_OUTPUT_DIR/entry.txt` when the grader sets it), UTF-8,
one line, 1–200 characters. It checks the line first: non-empty,
at most 200 characters counted per code point, and no line breaks.

```sh
node main.ts
```
