One funny line about a haircut that disappointed both the customer
and the reference photo he showed the barber.

## The line

> My barber asked if I wanted my hair like the photo, so I said yes, and now the photo and I are both disappointed.

113 characters, one line, one read. The setup promises the usual
complaint — a haircut that missed the picture — and the twist lands
on the last words: the photo is disappointed too, as if it had
hoped for better as well.

## How it runs

`main.ts` (Node 22) writes the line to `/output/entry.txt`
(`$MAKEFUN_OUTPUT_DIR/entry.txt` when the grader sets it), UTF-8,
one line, 1–200 characters. It checks the line first: non-empty,
at most 200 characters counted per code point, and no line breaks.

```sh
node main.ts
```
